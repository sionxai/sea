# 바다숲 키트

성게 패각 생태 블록에 해조류 포자를 붙인 바다 식목 키트를 소개하고, 주문·추천 해역 확인·이식 인증까지 체험할 수 있는 로컬 MVP입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 첫 요청 시 `data/ocean-forest.db`가 생성되고 시연 데이터가 자동으로 추가됩니다.

## 개발용 시연 계정

개발 서버에서는 시연 계정이 자동 생성되고 로그인 화면에 자격정보가 표시됩니다. `DEMO_ACCOUNT_PASSWORD`로 개발용 비밀번호를 바꿀 수 있습니다. 시연 계정은 운영 환경에서는 생성되지 않습니다.

## 검증

```bash
npm run typecheck
npm run build
```

현재 버전은 SQLite 로컬 백엔드, 이메일 세션 로그인, 테스트 결제를 사용합니다. 운영 환경에서는 안전하게 무작위 생성한 32자 이상의 `SESSION_SECRET`이 반드시 필요하며, 저장소의 예시 환경 파일에는 값을 넣지 않습니다. 실제 운영 전에는 OAuth, PG 결제와 운영용 데이터베이스로 교체해야 합니다.

기존 로컬 DB에 생성된 체험 계정은 운영 모드에서 인증과 세션 사용이 모두 차단됩니다. 운영 데이터 이전 전에는 DB를 백업한 뒤 체험 계정을 별도로 비활성화하고, 세션 비밀키를 회전해 기존 쿠키를 무효화하세요.

`public/images`의 제품·해역 이미지는 서비스 디자인 시연을 위해 생성된 AI 이미지이며 실제 상품 또는 특정 해역의 현장 사진이 아닙니다.
